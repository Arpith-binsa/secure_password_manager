About Secure Password Manager

This application is a cybersecurity project designed to demonstrate secure password management through encryption, authentication, and a web-based interface.

Security Features

  • Master passwords are securely hashed using Scrypt.
  • Stored credentials are encrypted using AES-256-GCM.
  • Encryption keys are derived using Scrypt.
  • CSRF protection is enabled for protected forms.
  • SQLAlchemy is used to reduce SQL injection risks.
  • Session cookies use HTTPOnly and SameSite protections.
  • Security headers are applied to HTTP responses.
  • Failed login attempts are temporarily restricted.

Password Generator

Password generation is integrated directly into the credential form. Users can choose the password length and character types before generating a password.
